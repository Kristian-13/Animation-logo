# Coca-Cola 3D Rotation — Kristián

Jednostránkový web s plechovkou Coca-Coly, která se po najetí myší otočí (CSS 3D efekt).

**Repozitář:** https://github.com/Kristian-13/Animation-logo

## Co jsem upravil
- jméno „Ralph“ nahrazeno jménem **Kristián**
- na plechovce je místo nápisu „Coca-Cola“ jméno **Kristián** ve skriptovém písmu (Great Vibes) s „ocasem“ pod textem jako u cola loga
- místo skal **ledový svět**: ledový podstavec, ledové kostky a krystaly (vlastní SVG)
- bublinky, které stoupají za plechovkou a po najetí myší zrychlí
- nové pozadí: noční modrá s červenou září za plechovkou a ledovým světlem zespodu (čisté CSS)
- bílý text a světlý čárový kód, aby byly na tmavém pozadí čitelné
- vlastní titulek stránky

## Technologie
- HTML5, CSS3 (bez JavaScriptu)

## Jak spustit
Otevři `index.html` v prohlížeči a najeď myší na plechovku.

## Zdroje
- Předloha: projekt „Coca-Cola 3D Rotation“ od Umeshe Joshiho („Ralph“)
- Písma: Karantina, Poppins, Great Vibes (Google Fonts)
- Ledové objekty a bublinky: vlastní tvorba (SVG a CSS)
- Logo a značka Coca-Cola použity pouze pro školní účely.
